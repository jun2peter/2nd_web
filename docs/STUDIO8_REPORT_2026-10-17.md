# Archive Studio 8 보고서 (2026-10-17 저녁 세션)

어제 계획표(`docs/ROADMAP_STUDIO6.md`)에서 남아 있던 항목을 이 세션에서 구현했습니다. 편집기를 열면 왼쪽 위 로고가 **ARCHIVE STUDIO 8**이어야 새 버전입니다(아니면 Ctrl+Shift+R).

## 1. 한 줄 요약

편집기 화면이 바뀌었습니다: 선택하면 위에 뜨는 **검은 툴바**, 상단 **줌 묶음·눈금자·컬럼·⌘K·?·파일 메뉴**, 왼쪽 **요소 타일과 자산 패널**, 작업할 때마다 뜨는 **토스트 알림**, 빈 페이지 안내. 기능으로는 템플릿·체크포인트·GitHub 원클릭 게시·색 팔레트/스포이트·눈금자와 가이드·컬럼 그리드·거리 표시·마스크·듀오톤·그라디언트 편집기·폼·다크 모드·접근성/SEO 검수·sitemap/404, 컴포넌트 4종(Lottie·가로 스크롤·글리치/픽셀·3D 커버플로우)이 들어갔습니다.

## 2. 써보는 법 (항목별)

### 편집기 화면 (B14 · B19)
- **선택 툴바**: 요소를 클릭하면 바로 위에 검은 툴바가 떠요. 글자 편집(T)·캔버스 가운데 정렬·복제·앞뒤·잠금·숨김·삭제. 여러 개를 고르면 정렬 6개와 분배 2개가 들어갑니다.
- **⌘K 명령 팔레트**: `Ctrl+K`. "이미지", "페이지", "검수", "템플릿"처럼 치고 Enter. 최근 쓴 명령이 위로 올라와요.
- **단축키 표**: `?` 키 또는 상단 `?` 버튼.
- **줌**: 상단 − / % / ＋ / 맞춤, `Ctrl+휠`, `Ctrl+0`, `Ctrl+=` `Ctrl+-`.
- **파일 ▾ 메뉴**: 백업 JSON · 불러오기 · 체크포인트 · 게시(GitHub 연결) · 복사해서 붙여넣기 게시 · 게시본으로 되돌리기.
- **토스트**: 복사·붙여넣기·저장 같은 결과가 화면 아래에 잠깐 떠요(눌러서 닫기).
- **빈 페이지**: 요소가 없는 페이지에 안내 카드가 뜨고, 바로 템플릿·텍스트·이미지·⌘K로 시작할 수 있어요.

### 색 팔레트 · 스포이트 (B17)
- 요소를 고르고 **모양** 패널을 열면 맨 위에 **색 띠**가 있어요. 사이트에서 이미 쓰는 색 + 최근 쓴 색. 색 칸(글자색·배경·선 색)을 한 번 누른 뒤 색 동그라미를 누르면 그 칸에 들어가요.
- **⌖ 스포이트**(Chrome·Edge): 화면 어디서든 색을 집어요.
- 색 칸마다 **색 고르기**가 붙었고, 글자 칸에는 `rgba(...)`나 그라디언트를 그대로 써도 돼요.

### 눈금자 · 가이드 · 컬럼 그리드 · 거리 표시 (B18 · B6)
- `Ctrl+R` 또는 상단 **눈금자**: 위·왼쪽에 눈금자가 생겨요. 눈금자에서 캔버스로 **끌어내리면 가이드**가 생기고, 가이드는 끌어서 옮기고 더블클릭으로 지워요. 요소는 가이드에 자석처럼 붙어요. 페이지마다 따로 저장돼요.
- 페이지 설정 → **컬럼 수 / 컬럼 간격 / 좌우 여백**: 분홍 컬럼 오버레이가 깔리고 요소가 컬럼 가장자리에 붙어요. `Ctrl+'`로 숨겼다 보여요.
- 요소를 끌면 가장 가까운 이웃까지의 **거리 숫자**(빨간 라벨)가 좌우·상하로 보여요.

### 자산 패널 (B15)
- 왼쪽 **자산**: 사이트에서 쓰는 이미지·영상·오디오가 썸네일로 모여요. **선택**(쓰는 요소로 점프) · **＋**(캔버스에 새로 넣기) · **교체**(쓰는 모든 곳에서 한 번에 바꾸기). 줄을 캔버스로 **끌어다 놓으면** 그 자리에 새 요소가 생겨요.

### 섹션·페이지 템플릿 (B16)
- 요소 추가 → **섹션 템플릿** 또는 ⌘K "템플릿". 섹션 12종(히어로 2종·소개·이미지 2열/3열·프로젝트 목록·인용·연락처·슬라이드쇼·비포/애프터·띠 문구·푸터)은 현재 페이지 맨 아래에 들어가고 바로 선택돼요. 페이지 탭의 4종(포트폴리오 홈·소개·프로젝트 상세·연락처)은 새 페이지를 만들어요.
- 들어간 사진 자리는 비어 있어요(IMAGE 표시). 자산 패널이나 드롭으로 바꾸세요.

### 체크포인트 (B13)
- `Ctrl+Shift+S`로 지금 상태를 이름 없이 저장, 파일 ▾ → **체크포인트…**에서 이름 붙여 저장·복원·JSON 내려받기·삭제. 복원 전에는 "복원 전 자동"이 먼저 저장돼요. 브라우저(IndexedDB)에 최대 30개.

### GitHub 원클릭 게시 · 미디어 업로드 (B12)
- 상단 **게시** 또는 `Ctrl+Shift+P`. 1번 칸에 **fine-grained 토큰**(이 저장소만, Contents 읽기·쓰기)을 붙여넣고 **연결 확인** → **지금 게시**. 토큰은 이 브라우저에만 저장돼요. 게시 전에 "게시 전 자동" 체크포인트가 저장되고, 공개 주소가 설정돼 있으면 sitemap.xml도 함께 올라가요.
- 토큰이 없으면 2번 **JSON 복사하고 GitHub 열기**(기존 방식)를 쓰세요.
- 3번 **미디어 파일 올리기**: 파일당 25MB까지 `/media/파일명`으로 올라가요. 토큰이 있으면 큰 파일을 캔버스에 끌어다 놓을 때도 자동으로 올라가요(게시 후 보임).
- 아직 확인 못 한 것: 실제 토큰으로 커밋이 성공하는지는 토큰이 있어야 확인할 수 있어서 UI와 오류 처리까지만 검증했어요. 첫 게시는 작은 변경으로 해 보세요.

### 이미지·영상 표현 (A13 · A15 · A16)
- **마스크** (모양 패널): 아래/위/왼쪽/오른쪽/양옆/위아래로 흐려짐, 비네트, **이미지 마스크**(PNG의 불투명한 부분 또는 흰 부분만 보임). 붓 자국·찢어진 종이 같은 PNG를 "작은 마스크 파일 바로 넣기"로 넣으세요.
- **듀오톤**: 체크하고 어두운 색·밝은 색 두 개를 고르면 사진·영상이 두 색으로 물들어요.
- **배경 그라디언트 편집…**: 선형/원형/원뿔, 각도, 색 2~5개와 위치, 프리셋(노을·바다·흑백·흰색→투명·빛). 바로 미리보기.
- 컴포넌트 **이미지 글리치 · 픽셀**: 글리치(RGB+조각)·픽셀 모자이크→선명·스캔라인·RGB만. 호버 중/항상/스크롤 속도.
- 컴포넌트 **3D 커버플로우**: 이미지 한 줄에 하나(`주소 | 캡션 | 링크`). 드래그·휠·←→·클릭·자동 넘김.
- 컴포넌트 **Lottie 애니메이션**: After Effects에서 내보낸 `.json`/`.lottie` 주소. 항상·호버·화면 진입·클릭·스크롤 스크럽.
- 컴포넌트 **가로 스크롤 섹션**: 상자를 길게(2400px) 만들면 스크롤하는 동안 카드가 옆으로 지나가요.

### 폼 (C4)
- 요소 추가 → **폼**. Formspree·Getform·Web3Forms 같은 서비스에서 폼을 만들고 받은 주소를 **받을 주소**에 넣으세요. 칸(이름·이메일·전화·제목·메시지) 체크, 추가 칸은 `라벨 | 종류` 한 줄씩. 주소가 없으면 공개 화면에서 "받을 주소가 아직 설정되지 않았어요"가 떠요.

### 다크 모드 · 공개 주소 · 검수 (C5 · C6 · C7)
- 사이트 설정 → **방문자 다크 모드 버튼** 체크: 공개 화면 왼쪽 아래 ☾ 버튼이 생기고, 페이지 배경과 글자색이 다크 색으로 바뀌어요(사진·버튼·도형은 그대로). 방문자 선택은 브라우저에 기억돼요.
- 사이트 설정 → **공개 주소**: sitemap.xml에 쓰여요. 게시 창에서 내려받거나, 토큰 게시 때 자동으로 올라가요. 저장소에 `404.html`도 추가했어요(없는 주소로 오면 처음으로 보내는 페이지).
- **검수**에 추가된 경고: 대제목(h1) 없음/여러 개, 제목 단계 건너뜀, 12px보다 작은 글자, 글자·배경 대비 3:1 미만, 검색 설명 없음, 공유 이미지 없음, 폼 주소 없음, http 링크, 호버 교체 이미지 없음, 마스크 이미지 없음, 공개 주소 없음.

- 모든 JS를 `.mjs`로 복사해 `node --check` 통과.
- `?view=archive&edit=1`(편집기)·`?view=archive&draft=1`(공개 화면)·`components/playground.html?c=…`(컴포넌트 4종) 콘솔 에러 0개.
- 브라우저 스크립트로 실제 동작 확인: 선택 툴바(단일 9개·다중 12개 버튼), 팔레트 47개 명령·검색, 단축키 표 28줄, 줌 버튼, 파일 메뉴, 눈금자→가이드 생성(240), 컬럼 12개, 스와치 적용, 거리 라벨(66·150), 템플릿 12+4(인용 섹션 2블록·연락처 페이지 10블록), 체크포인트 저장/삭제, 게시 창(소유자·저장소·브랜치 자동 입력, 토큰 없으면 비활성), 마스크 gradient, 듀오톤 filter url, 그라디언트 프리셋 적용, 폼 3→4칸·inert, 공개 화면 다크 토글·폼 제출 안내, 컴포넌트 4종 렌더.
- 테스트로 만든 블록과 설정은 모두 되돌려 사용자의 브라우저 초안은 원래대로(Home 2개 · Page 2 3개).

## 6. 8.1 추가 — 편집기 새 얼굴

- **왜**: 기능은 늘었는데 패널·툴바·입력칸 디자인이 그대로라 "똑같다"고 느껴졌어요. 그래서 편집기 화면 자체를 다시 그렸습니다.
- **무엇이 바뀌었나**: UI 글꼴(Pretendard), 색·간격·둥글기 토큰 통일, 왼쪽 패널을 **탭 4개**(레이어 · ＋ 추가 · 자산 · 설정)로 정리해 스크롤이 짧아짐, 상단 바는 Design/Motion·Desktop/Tablet/Mobile·줌이 **세그먼트 컨트롤**, 나머지는 아이콘 버튼과 구분선, **게시**는 보라색 주 버튼. 레이어 줄·페이지 줄·요소 타일·인스펙터 섹션 헤더(펼침 화살표)·입력칸(30px, 포커스 링)도 새 스타일.
- **편집기 다크 테마**: 상단 ◐ 버튼 또는 `Ctrl+Shift+D`. 패널·툴바·메뉴·팔레트·모달까지 어두워지고 캔버스(작업물)는 그대로예요. 선택은 브라우저에 기억돼요.
- 처음 열 때 페이지가 비어 있으면 **＋ 추가** 탭이 먼저 열려요. 아니면 마지막에 보던 탭.
